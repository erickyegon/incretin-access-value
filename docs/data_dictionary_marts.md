# Data dictionary: marts (generated)

Generated by `scripts/build/gen_data_dictionary_marts.py` from the warehouse schema and `dbt/models/marts/schema.yml`. The conventions that apply to every mart are in [data_dictionary.md](data_dictionary.md):
NDC is the drug code (no HCPCS J-codes), SDUD counts under 11 are suppressed, and amounts are gross of rebates.
